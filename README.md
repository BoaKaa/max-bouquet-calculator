# «Состав и цена» — мини-приложение для MAX

Рабочая мобильная сборка калькулятора съедобных букетов. Она запускается без установки программ и может быть опубликована как обычный статический сайт по HTTPS.

## Что уже работает

- первый запуск без регистрации;
- четыре реальных примера от Татьяны с фотографиями;
- расчёт материалов, работы, себестоимости, цены продажи и прибыли;
- единая цена продукта: изменение автоматически пересчитывает все композиции;
- проверка запасов и список недостающего;
- копирование примера в личные композиции;
- создание своей композиции и добавление продукта прямо в состав;
- удаление устаревших личных композиций с подтверждением;
- разделы «Запасы» и «Покупки»;
- операция «Купила ещё»: обновляет остаток и закупочную цену;
- режим изготовления с таймером или без него;
- история изготовленных композиций с фильтром по периоду;
- итоги по себестоимости, выручке и прибыли;
- сравнение двух или трёх работ, включая одинаковые букеты разных дат;
- неизменяемый снимок закупочных цен на момент изготовления;
- собственное время изготовления для каждой композиции;
- списание использованных запасов;
- добавление своих продуктов, материалов и цветов;
- обнуление одной позиции или сразу всех запасов;
- удаление отдельных покупок и очистка всего списка;
- собственные фотографии пользовательских композиций со сжатием перед сохранением;
- экспорт и восстановление резервной копии JSON;
- сохранение данных в `localStorage` между перезапусками браузера.

## Запуск на Windows 11 без npm

1. Полностью распакуйте ZIP-архив.
2. Откройте распакованную папку `max-bouquet-prototype`.
3. Дважды щёлкните `START-WINDOWS.bat`.

Можно также просто дважды щёлкнуть `index.html`. Приложение откроется в браузере по умолчанию. Node.js, npm, Python и установка дополнительных программ не требуются.

Важно: не запускайте файл прямо из окна ZIP-архива — сначала выберите «Извлечь всё».

## Запуск через локальный сервер — необязательно

Если Node.js уже установлен, в каталоге проекта по-прежнему можно выполнить:

```bash
npm run dev
```

и открыть `http://localhost:4173`.

Для разработчика проверка расчётного ядра запускается командой:

```bash
npm test
```

## Зафиксированные продуктовые решения

- история изготовлений является обязательной частью приложения;
- старые расчёты не пересчитываются при изменении текущих закупочных цен;
- у каждой композиции можно установить своё время работы;
- пользователь может создавать любые собственные продукты и материалы;
- запасы и покупки можно очищать вручную.

## Хранение данных

Данные, история и фотографии сохраняются только в браузере на устройстве пользователя. Для переноса на другое устройство используйте резервную копию JSON. Токен бота и другие секреты в проект не добавляются.

## Следующий этап уже начат

В папке `production-app` находится технический каркас рабочей версии:

- React + TypeScript + Vite;
- IndexedDB через Dexie;
- официальный MAX Bridge;
- production-сборка в `production-app/dist`;
- отдельные тесты расчётного ядра.

Эта папка предназначена для разработки и будущей публикации по HTTPS. Для обычного просмотра на Windows по-прежнему используйте `START-WINDOWS.bat` в корне.

Следующий технический этап после проверки опубликованной версии:

1. перенести интерфейс в React + TypeScript + Vite;
2. заменить `localStorage` на IndexedDB через Dexie;
3. перенести локальные данные и фотографии в IndexedDB;
4. подключить MAX Bridge и обработку системной кнопки «Назад»;
5. проверить сохранность IndexedDB внутри MAX на Android, iOS, вебе и десктопе;
6. подготовить тестовый HTTPS-хостинг и привязать URL к боту.

Секретов и токена бота в проекте нет и быть не должно.
